# NovelKit Web 面板

一个**零第三方依赖**（后端纯标准库、前端原生 JS，无构建步骤）的面板，
本机与云服务器都能部署。

## 快速开始

> 从零开始，把 `<仓库地址>` 换成你的仓库 URL。

```bash
git clone <仓库地址> novelkit
cd novelkit
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env              # 填入 API_KEY（默认 DeepSeek）
./webpanel/run.sh --open          # → http://127.0.0.1:8897/
```

云服务器（带访问令牌 + systemd 常驻）：

```bash
cp webpanel/panel.env.example webpanel/panel.env
TOKEN="$(python3 -c 'import secrets;print(secrets.token_urlsafe(24))')"
sed -i "s|^#\?PANEL_TOKEN=.*|PANEL_TOKEN=$TOKEN|" webpanel/panel.env
chmod 600 webpanel/panel.env
sudo ./deploy/install-services.sh
# 打开 http://<服务器IP>:8897/?token=$TOKEN 换 Cookie，之后正常访问
```

### 日常启动方式

```bash
# 方式一：用封装脚本（推荐）
./webpanel/run.sh                 # http://127.0.0.1:8897/（仅本机）
./webpanel/run.sh --port 9000     # 换端口
./webpanel/run.sh --open          # 启动后自动打开浏览器
./webpanel/run.sh --host 0.0.0.0 --token <令牌>   # 云服务器（见 deploy/cloud.md）

# 方式二：直接用解释器
.venv/bin/python webpanel/server.py

# 方式三：systemd 常驻
sudo ./deploy/install-services.sh
```

> `webpanel/panel.env`（模板 `panel.env.example`）可预置 `PANEL_HOST` / `PANEL_PORT` /
> `PANEL_TOKEN`，`run.sh`、systemd 单元与 `deploy/services.sh` 都读它。

> 面板本身**零第三方依赖**：用系统 `python3` 也能启动，浏览、对照、术语库、本地编辑
> 全部正常。只有**翻译任务**需要 `openai`，所以推荐用 `.venv/bin/python` 启动。

## 界面与操作

**信息架构：作品是第一级分类。** 在左侧选中某个作品后，它的三个二级视图
（中英对照 / 术语库 / 编辑）都只服务于该作品——各作品的数据彼此独立，互不干扰：

```
概览                     ← 全局，所有作品
作品
  my-novel   26/766
    ⇄ 中英对照
    ⌗ 术语库
    ✎ 编辑
全局
  ⊕ 导入 EPUB
  ⚙ 环境配置
工具
  ↗ 作品导出工具          ← 可选，第三方；经面板反代 /tools/tomato/ 打开
```

| 二级视图 | 能做什么 |
| --- | --- |
| 中英对照 | 同一屏左右并排中文原文与英文译文，逐段对齐；并排/仅中文/仅英文、字号、章内搜索、前后章跳转；**底部「本章操作」可直接翻译本章、局部重译、Refine** |
| 术语库 | 该作品的术语总表（按首次出现章节）、按章明细（一章一张卡片、卡内三列）、冲突流水，并可手工增删术语 |
| 编辑 | 直接读写该作品的 `*_origin.txt` / `*_translated.txt`；**写前自动备份**到 `.backups/`，原子替换；可新建章节、提示缺原文 / 缺译文的章节 |

### 本章操作（已并入中英对照）

阅读页底部就是这一章的操作台：

- **翻译本章 / 重新翻译本章**：后台启动 `scripts/translate.py --dir <work> --chapter <n> --zh`，
  可勾选 `--rag`。同一时刻只允许一个任务（翻译必须按章节顺序推进，
  并发会互相污染"先到先得"的术语库）。
- **任务日志默认收起**，只占一行：状态 + 最后一条输出 + 「展开日志 / 取消任务」。
  展开时日志最高 190px 并可滚动；**失败时自动展开**让你直接看到报错，成功后自动收起。
  这样运行中的任务不会把阅读区挤掉。
- **本章新术语**同样默认收起（有的章节上百条），点标题展开。
- **本章操作整块可折叠**（`<details>`），展开/收起状态记在 localStorage，下次进来保持。
- **术语高亮**：本章正文里出现的术语用荧光笔底纹 + 实线下划线标出，**中文词条与它的英文译法同色双向高亮**
  （英文侧底色更淡，不挡阅读）。**每个术语一个颜色**：色相用黄金角采样（`index × 137.508°`），
  词条多也不易撞色；悬停显示"中文 → 译法"。只标真正出现过的词，取"本章新术语 + 全书固定/语境术语"
  的交集（最多 400 个）；同一术语的多个译法（`A / B` 或语境映射）会全部参与匹配。
  可在「本章操作」里勾选开关。
- **重建本章术语**：默认写术语库是**合并**语义（同名键更新、本次没提到的保留，
  这样人工用「＋指定术语」预登记到未来章节的词条不会被翻译抹掉）。
  需要"丢弃旧词条、按本次译文整体重建"时勾选「重建本章术语」，
  勾上后文案会提示将丢弃多少条。
- **分段处理（重译 / Refine 已合并为一个动作）**：勾选「分段选择」后，点正文
  **任意一侧**即可选中该段；选中后点「处理选中的 N 段」，AI 会逐段评审并修订，
  改动理由显示在段落角上。想让它**完全重新翻译**（不参考现译）就勾上
  「忽略现有译文」，效果等同重译但同样会给理由。上下文、术语库、RAG 检索与整章翻译
  **完全一致**（统一走 `novelkit/prompt.py`），未勾选的段落逐字节保持原样。
  一个对齐行含多段中文时整行一起处理。
  命令行层面 `scripts/retranslate.py`（纯重译）与 `scripts/refine.py --ignore-draft` 都仍然可用。
- **RAG 默认开启**，但会**记住上次的选择**（localStorage）：首次使用默认勾选，
  你手动改过之后就沿用你的选择，刷新/换章节都不会被重置。
- **补充要求输入框**：整章翻译 / 局部重译 / Refine 各有一个「▸ 提示词」按钮，
  展开即可写本次任务的额外要求（失焦自动保存，Ctrl+S 立即保存），
  以 `<user_supplement>` 注入提示词。内容存在 `webpanel/prompt_snippets.json`。
- **任务不刷页，且只更新变化的部分**：启动任务后日志挂进常驻槽位；任务结束时
  按**行内容指纹**逐行比对——相同的不碰、不同的只替换那一行、行数变了才整块重建。
  统计标签、术语卡片、摘要、高亮计数同步更新；工具栏、滚动位置、筛选状态、
  任务日志、框选中的文字、批注图标的渐显状态都保留。
  启动任务**不会**自动滚动到日志（不打扰正在阅读的位置）。
- **"刚改好"提示**：任务结束时对英文段落做段落级 diff，只把**这次改动的段落**
  逐字显示出来并短暂闪烁；刷新页面不会重放（没有对比基准）。
- **Refine 批注**：改动的段落在右上角显示 ✎ 图标（琥珀色=已修改，灰色=判定无需修改），
  图标渐显；悬停弹出**自绘卡片**（标题 / 相对时间 / 状态点 / 理由正文；样式对齐 dsh 的悬浮卡，
  而非浏览器的原生 title）；**点击图标可把卡片固定住**，直到点击别处或按 Esc，
  固定时卡片可选中复制、图标描边高亮；理由正文**直接显示**（不做逐字）；理由存在 `<章节>_refine.json`，按行合并保留历史，
  且只在段落内容仍与批注一致时才显示，避免理由过时误导。
- **指定术语**：术语库页与「本章操作」都有「＋ 指定术语」按钮，弹出模态框录入
  词条 / 译法 / 类别 / 语境 / **作用范围** / 写入章节。
  作用范围有三档：
  - **仅本章**（默认）→ 写入 `glossary_<n>.json`，遵循先到先得；
  - **整本书** → 写入 `<作品>/glossary.json`，**这部作品里优先级最高**
    （高于全局术语库，高于所有章节），用来登记原著术语与关键设定；
  - **全局术语库** → 写入 `config/glossary.json`，**所有作品共用**。
    这是唯一由人手工维护的一层：自动翻译永不覆盖它，面板里可以新增/修改
    （勾选「强制覆盖」），总表里标为「全局」。
  优先级：**作品术语库 ＞ 全局 config/glossary.json ＞ 章节术语库**；
  章节范围改不动作品级/全局条目，会提示改作用范围。遵守"先到先得"：新词写入指定章，
  已存在的词条回写到**最早确立它的那一章**；不同值需显式勾选「强制覆盖」；
  输入词条时会实时查询并提示已有记录（并标明来源是作品级 / 全局 / 第几章）。

### 章内搜索与删除本章

- 工具栏的搜索框旁边有 **↑ / ↓** 跳到上一个 / 下一个命中，输入框内**回车 = 下一个**、
  **Shift+回车（或 ↑/↓）= 上一个**、**Esc = 清空**；命中计数显示成 `2/7`，
  当前定位到的命中会加一圈描边，并自动滚到视野中间；
- 工具栏最右侧有 **删除本章**（危险色）：确认后把这一章的所有文件
  （原文 / 译文 / 回译 / 评审 / 精修 / 本章术语）**先备份到作品的 `.backups/`** 再删除，
  然后自动跳到相邻章。确认框里会写清"备份到哪里"和"删完跳到哪一章"。

### 阅读位置

- 打开一部作品时**接着上次读到的那一章**：每部作品的阅读位置分开记（存在浏览器里），
  在作品之间来回切换不会互相影响；
- **第一次**打开某部作品时，有简介就先停在简介（第 0 章），没有就进第 1 章；
- 记住的章号如果已经不存在（文件被删或重编号），自动回退到简介 / 第一章；
- 浏览器存储不可用（隐私模式等）时静默退回默认行为，不影响使用。

### 编辑

「编辑」视图把本地文件直接摊开给你改，是纯本地操作，不涉及任何发布平台：

- 顶部选择章节（列出所有章号，并标明原文 / 译文是否存在）与文本类型（原文 / 译文）；
- 中间是等宽字体的多行编辑区，**一行一段**（与翻译流水线的约定一致）；
- 「保存」写回 `<作品>/<n>_origin.txt` 或 `<作品>/<n>_translated.txt`，
  写前把旧文件备份到 `<作品>/.backups/`（文件名带时间戳），保存后提示字数、行数与备份路径；
- 「新建章节」输入章号后得到**空白缓冲区**，只有点了保存才真的创建文件；
- 有未保存改动时切换章节 / 文本类型会先确认，避免误丢；
- 页面会提示缺原文 / 缺译文的章节，方便补录或定位；
- 底部「作品」卡片有**重命名作品**与**删除整本书**：
  - 重命名改的是作品目录名，成功后侧栏、地址栏、以及"上次读到第几章"的记忆
    都会一起更新；
  - 删除**不是真删**：整个目录被**移动**到工作区根的 `works/.trash/`（带时间戳），
    随时能捞回来；删除后自动回到概览。

### 关于段落对齐（Gale-Church）

原文与译文都是"一行一段"，但译文常把 2~3 段并成一段、偶尔也拆开
（例如中文 90 段 / 英文 66 段）。**按下标配对或只按单段长度比例配对都会整体串行一格**。

现在改用经典做法（Gale & Church, 1993）：把 `log(英文段长 / 中文段长)` 建模为正态分布，
用 DP 在 `1:1 / 1:0 / 0:1 / 2:1 / 1:2 / 2:2 / 3:1 / 1:3` 这些分组里找总代价最小的组合。
效果：

- 合并点被正确识别，`【剩余人数：10000】` 正确配到 `[Remaining Population: 10,000]`；
- 一个对齐行内若有多个段落，会在同一格里分行显示，右下角悬停可看到 `2:1` 这样的比例角标；
- **不丢不重**：两侧每个段落都恰好出现一次；
- 结果按 (路径, mtime) 缓存，平均 26ms/章。

### 导入 EPUB

`全局 → 导入 EPUB`：

- 点击或拖入 `.epub`（**只在本机解析**，不上传任何服务器）；
- 解析完成后**上传区自动收起**，页面焦点交给章节表；要换文件点「**取消导入**」即可
  回到选择文件的状态（取消只丢弃本次解析结果，不写任何文件）；
- 列出**全部**文档条目（下标、标题、字数、段数），并标出：`目录`（目录/导航文档）、
  `第 N 章`（能解析出章节号，可点击只看该章）、`简介`、`空`；
- **只有"目录/导航文档"会被自动识别并排除**：其它标题（番外、后记、尾声……）
  各种写法太多，猜错比不猜更糟，因此不做特殊标题猜测，一律交给勾选；
- **默认勾选简介之后的全部非空条目**（目录文档除外），因此特殊标题不会被漏掉；
- **默认包含简介**：第一个编号章节之前、非目录的最后一条会被建议为简介，可下拉改选；
- 勾选「**作为简介章节导入**」后，那一条在表里**置灰且不可再勾选**，导入时只写成
  `0_origin.txt`（简介），**不会**再作为正文章节重复写一遍；
- 若勾选里漏了原书的某一章（章节号有缺口），导入后会提示"漏选了第 N 章"；
- 每行可**预览**正文前 320 字；
- 可设置作品名与正文起始章号；
- 目标已有同名章节时**默认拒绝写入**，需显式勾选「覆盖已有文件」；
- 导入完成后**直接跳转到该作品的「中英对照」**，接着就能翻译；侧栏会同时出现新作品。

> 不同 EPUB 的封面 / 版权页 / 目录页数量不一样，正文起始位置差异很大。
> 导入时把这件事交给用户确认（并给出建议值），避免"默默导错章"。

### 环境配置

`全局 → 环境配置`，三块内容：

**① 当前状态**（一行一项、从上到下列出）

- 每项显示键名、说明与「已配置 / 未配置」徽标；
- 已配置的只显示**长度与前 6 位**，**绝不回显完整密钥**；可选项显示当前值或内置默认；
- 标题旁显示 `.env` 路径与最近修改时间；远程模式下多一个「退出登录」。

**② 模型 API**：`API_BASE_URL` / `API_MODEL` / `API_KEY`，默认 DeepSeek
（`https://api.deepseek.com` / `deepseek-flash`）。地址与模型名会回显，Key 只显示是否已配置；
面板任务与命令行 `python scripts/translate.py` 共用这一份 `.env`。
点「验证」会向模型服务发一次最小请求（`GET /models`），直接告诉你地址与 Key 是否可用。

**③ 外部工具地址**：**服务端**要访问到的地址（默认 `127.0.0.1:18423`），带可达性圆点。
对应的第三方工具（作品导出）**不由本项目提供**，安装方式见根目录 README；
界面上会写明**只应用于你自己拥有版权或已获授权的作品**，并可点击跳到上游项目主页。

### 外部工具反代（/tools/&lt;id&gt;/）

侧栏「工具」不直连外部地址，而是打开面板同源路径 `/tools/<id>/`，由服务端转发：

| 路径 | 行为 |
| --- | --- |
| `/tools/tomato/` | 转发到目标 `/`，并把响应体里的根绝对路径（`/assets/`、`/api/`、`/download/`、`/download-zip/`）改写成 `/tools/tomato/...` |
| `/tools/tomato/<其余>` | 原样转发（任意方法）；`Location`、`Set-Cookie` 的 Path 收进子路径 |
| `/tools/tomato` | 302 到带结尾斜杠的版本 |
| 其它 id | 404（不在注册表里的一律不转发） |

- 改写前缀写在 `services/tools.py` 的 `proxy_prefixes`，换别的 WebUI 时按它实际用的路径改；
- 上游必须是**纯 HTTP 轮询**型界面：本例的下载器 WebUI 靠自己轮询接口刷新进度，
  不需要 WebSocket/SSE。若某个工具依赖 WebSocket，这个反代不适用
  （面板**自身**的任务日志走 SSE，见下方 `/api/jobs/<id>/stream`）；
- 上游若坚持 gzip 压缩（不理会 `Accept-Encoding: identity`），响应体会原样透传、
  不做改写，此时它的静态资源仍可能 404；
- 只允许打到配置里那一台主机（`../`、`//` 不会改主机名）；
- 云服务器上**不需要**对外开放下载器端口，面板的访问令牌就是它的门禁；
  下载器自带的 `--password` 建议照开做纵深防御；
- `--no-tool-proxy`（或 `PANEL_TOOL_PROXY=0`）可整体关闭反代，侧栏退回直连。

### 框选复制

从阅读区框选复制时**只输出正文**，不会混进别的东西：

- 装饰性元素（批注图标 ✎、合并角标 `2:1`、勾选框、占位提示、表头统计）
  一律 `user-select: none`，压根不进选区；
- 复制事件里再做一次规整：逐行去空白、丢掉空行。
  两栏栅格是块级元素，选区天然夹杂空行，粘到富文本编辑器里会变成一个个空段落；
- 只有选区确实落在正文内才接管，页面别处的复制行为不变。

### 交互约定

- **按钮**：尺寸只有两档（默认 / `sm`），类型只有四种（`primary` 主操作、默认次操作、
  `danger` 危险、`ghost` 折叠开关）。**同类动作必须同外观**——例如
  "重译选中"与"Refine 选中"都是针对当前选择的主操作，都用 `primary`。
- **勾选项**：一律是 `<label class="check">` 包住 `<input type=checkbox>`，
  点文字即可切换；列表类勾选（中英对照的行、EPUB 导入的行）**整行可点**。
- **提示信息**：不用浏览器原生 `title`，一律用自绘悬浮卡片。

## 安全约定

- **本机模式（默认）**：只监听 `127.0.0.1`，并**拒绝非本机来源**的请求。
- **远程模式**：监听非回环地址时**必须**设置 `PANEL_TOKEN`，否则拒绝启动（fail-closed）。
  认证走 HttpOnly Cookie：页面未登录 302 到 `/login`，接口返回 401；
  首次可用 `http://<host>:<port>/?token=<令牌>` 换取 Cookie。Cookie 带 `SameSite=Lax`，
  写接口只接受 `application/json`（挡 CSRF）；反向代理透传 `X-Forwarded-Proto: https`
  时自动加 `Secure`。
- 页面上永远不显示 API Key 或访问令牌。
- **编辑写入**：先备份到 `.backups/`，再写临时文件并原子替换，不会留下半截章节；
  路径经过校验，不会写到作品目录之外。

云服务器部署（令牌、Nginx/HTTPS、防火墙、常见问题）见 [`../deploy/cloud.md`](../deploy/cloud.md)。
